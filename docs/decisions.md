### HG-18 schema-freeze checklist
1. Location `type` uses enum `location_types_v1` (HG-04).
2. `world.json` times are integers in 0-10 minutes (HG-05).
3. Accusation: visible options with stable IDs; correct IDs only in `truth.json`; 4 method and 4 motive options; culprit options = NPC IDs (HG-06).
4. NPC reply schema has `reply` and enum `mood` (HG-08).
5. `crime.type` enum = theft, disappearance, murder (HG-15).
6. Each NPC's files are isolated; `truth.json` is never referenced by any prompt template.
7. Every schema has a `schema_version` and a validator.
8. Training-data provenance fields exist (`teacher_model_id`, generator version) (HG-11).
