\begin{abstract}
Traditional video game Non-Player Characters (NPCs) typically suffer from either rigid, scripted predictability or unconstrained language model hallucinations that violate game rules and spatial reality. This report presents the architectural design and technical specification of a small-scale multi-agent simulation in which 5 to 10 autonomous game characters perceive a dynamic, discrete town environment, maintain private episodic memory streams, and execute actions governed by classical Artificial Intelligence algorithms. Classical algorithms---including $A^*$ search for deterministic pathfinding, Genetic Algorithms (GA) for multi-objective daily planning, Multi-Layer Perceptrons (MLP) for reflex action classification, and K-Means for unsupervised behavior analysis---manage physical navigation, resource allocation, and physics verification. Concurrently, a Large Language Model (LLM) functions strictly as a conversational brain, generating persona-consistent dialogue grounded solely in the NPC's private memory log. By establishing the simulation engine as the immutable ground truth, this hybrid framework eliminates state hallucinations while preserving emergent social dynamics and natural language interaction.
\end{abstract}

\vspace{1em}
\noindent\textbf{Keywords:} Multi-Agent Systems, Non-Player Characters, Classical AI, Genetic Algorithms, Grounded LLM, $A^*$ Pathfinding, Game Simulation.

\section{Project Overview}
% =========================================================================

\subsection{Problem Formulation and Motivation}
In interactive entertainment and synthetic simulations, Non-Player Characters (NPCs) have historically relied on Finite State Machines (FSMs) or static behavior trees. While computationally trivial and deterministic, these characters display zero episodic recall, fail to adapt to emergent events, and exhibit repetitive conversational dialogue. 

Recent advancements in generative artificial intelligence have prompted attempts to replace scripted logic entirely with Large Language Models (LLMs). However, pure LLM-driven agents introduce critical architectural flaws:
\begin{enumerate}
    \item \textbf{Factual and Physical Hallucination:} Generative models invent unearned items, claim impossible physical actions, or bypass geographic barriers.
    \item \textbf{Loss of Spatial Grounding:} Language models lack internal metric geometry and cannot reliably compute shortest paths or avoid collision zones without structured external engines.
    \item \textbf{Excessive Computational Overhead:} Querying frontier models for every low-level movement tick is computationally prohibitive and latency-heavy.
\end{enumerate}

To resolve this dichotomy, we propose a \textbf{Hybrid Multi-Agent Simulation}. The system populates a simulated town (comprising nodes such as Market, Caf\'e, Town Square, Library, Park, and Residential Homes) with 5 to 10 autonomous NPCs (e.g., Ahmed, Sara, Bilal). Each character maintains sensory constraints, an individual memory stream, and dynamic goal hierarchies, arbitrated through a clear division of responsibilities (Table~\ref{tab:hybrid_roles}).

\subsection{Academic Syllabus Integration}
Rather than reducing AI coursework to prompt engineering, this project centers on classical and modern foundational AI pillars:
\begin{itemize}
    \item \textbf{Graph Search ($A^*$, BFS):} Optimal point-to-point traversal across weighted topological maps.
    \item \textbf{Evolutionary Computation (GA):} Chromosome encoding, crossover, mutation, and elitism for multi-objective schedule planning.
    \item \textbf{Supervised Learning (ANN / MLP):} Feature extraction, forward propagation, loss optimization, and evaluation (confusion matrices, F1-scores).
    \item \textbf{Unsupervised Learning (K-Means):} Grouping high-dimensional agent trajectories to uncover emergent archetypes.
    \item \textbf{Grounded Generative AI:} Structured JSON prompt synthesis ensuring grounded, hallucination-free dialogue.
\end{itemize}

\section{Inspiration and Related Work}
% =========================================================================

\subsection{Generative Agents (Park et al., 2023)}
Park et al.~\cite{park2023generative} demonstrated that LLM-driven agents could exhibit coherent social behaviors in a 25-character virtual community (``Smallville''). Their core contribution was the \textbf{Memory Stream} architecture: agents record raw natural language observations, retrieve memories via recency, importance, and relevance metrics, and periodically synthesize higher-level reflections. While groundbreaking, Generative Agents relied on unconstrained LLM calls for physical planning, incurring severe compute costs and occasional spatial inconsistencies. Our architecture preserves the memory stream concept while transferring physical planning to deterministic classical algorithms.

\subsection{Narrative Evaluation and NARRA-Gym (Huang et al., 2026)}
Huang et al.~\cite{huang2026narra} benchmarked nine leading frontier LLMs in multi-turn interactive storytelling environments. Their findings revealed that even state-of-the-art models consistently fail at long-horizon consistency, character stability, and spatial bounds when operating without external structured harnesses. Decoupling the narrative dialogue layer from the physical simulator directly resolves these stability deficits.

\subsection{Text-Based Environments and Gym Standards}
Microsoft's TextWorld~\cite{cote2018textworld} established that discrete room environments and text interfaces provide rigorous, reproducible benchmarks for reinforcement learning and planning. Concurrently, the Gymnasium~\cite{gymnasium2023} and PettingZoo~\cite{pettingzoo2021} (Farama Foundation) standards formalize multi-agent simulation loops (`reset()`, `step()`, observation/action spaces). Our town engine adopts Gymnasium conventions, ensuring lightweight execution on standard multi-core CPUs without GPU dependencies.

\section{System Architecture and the Simulation Loop}
% =========================================================================

The simulation operates as an episodic, discrete-time loop where each tick represents a fixed quantum of virtual time (e.g., 5 simulation minutes), as illustrated in Figure~\ref{fig:system_arch}.

\caption{The closed perception-decision-action simulation loop governing agent behaviors.}
\label{fig:system_arch}

\subsection{Detailed Stages of the Simulation Tick}

\subsubsection{Stage 1: World State (Ground Truth)}
The central game engine maintains the objective ground truth of the universe:
\begin{equation}
    S_t = \langle \mathcal{G}, \mathcal{O}_t, \mathcal{A}_t, \tau_t \rangle
\end{equation}
where $\mathcal{G} = (V, E)$ represents the town graph topology, $\mathcal{O}_t$ denotes item placements and states, $\mathcal{A}_t$ represents character locations and inventories, and $\tau_t$ tracks the simulation clock.

\subsubsection{Stage 2: Perception Filtering}
To prevent omniscient knowledge leakage, each agent $i$ receives a filtered observation $o_{i, t} \subset S_t$ constrained by a spatial sensory radius $r_{\text{percept}}$:
\begin{equation}
    o_{i, t} = \{ e \in S_t \mid \text{dist}(\text{loc}(i), \text{loc}(e)) \le r_{\text{percept}} \}
\end{equation}
Events occurring beyond this sensory boundary are withheld from the character's cognitive pipeline.

\subsubsection{Stage 3: Internal NPC State Representation}
Each character maintains two persistent internal structures:
\begin{enumerate}
    \item \textbf{Episodic Memory Log ($M_i$):} An append-only chronological ledger of observations, dialogues, and interactions.
    \item \textbf{Goal and Trait Profile ($P_i$):} A static vector of personality traits (e.g., $\text{caution} \in [0, 1]$, $\text{curiosity} \in [0, 1]$) and a priority stack of active operational goals.
\end{enumerate}

\subsubsection{Stage 4: Hybrid Decision Engine}
Given internal state $\langle M_i, P_i \rangle$ and current observation $o_{i, t}$, the character evaluates whether physical navigation, multi-stop planning, reflexive action, or dialogue is required, dispatching the task to the respective algorithm.

\subsubsection{Stage 5: Action Execution and State Validation}
The proposed candidate action $a_i \in \{\text{Move}, \text{Talk}, \text{Examine}, \text{PickUp}, \text{Wait}\}$ is submitted to the simulation engine. The engine verifies physical feasibility (e.g., target object adjacency, path validity). Valid actions mutate the world state $S_{t+1}$ and advance the clock $\tau_{t+1}$.

\begin{quote}
\textbf{The Grounding Axiom:} World State is absolute truth. The language model may formulate dialogue and intent, but cannot modify physical coordinates, alter item inventories, or warp simulation time.
\end{quote}

\section{The AI Decision Engine: Classical AI and LLM Integration}
% =========================================================================

The decision engine routes computational subtasks to specialized algorithms, ensuring verifiable execution and linguistic richness (Figure~\ref{fig:decision_dispatch}).

\begin{figure}[htbp]

\subsection{Search and Pathfinding ($A^*$ and BFS)}
When an agent requires traversal between two distinct town nodes (e.g., Home to Market), the system invokes the $A^*$ search algorithm across the weighted town graph $G = (V, E)$. The evaluation function:
\begin{equation}
    f(n) = g(n) + h(n)
\end{equation}
combines exact path cost $g(n)$ from the origin with an admissible Euclidean distance heuristic $h(n)$ to the destination node. This guarantees mathematically optimal paths with zero computational hallucination.

\subsection{Genetic Algorithm for Multi-Objective Planning}
When an NPC must construct a daily itinerary balancing competing requirements, single-source shortest path algorithms fail. We formulate multi-objective daily scheduling as an evolutionary optimization problem (Figure~\ref{fig:ga_flow}).

\begin{figure}[htbp]
\centering
\includegraphics[width=0.92\textwidth]{../../assets/genetic_algorithm_flow.png}
\caption{Genetic algorithm chromosome structure, fitness evaluation, and evolutionary cycle.}
\label{fig:ga_flow}
\end{figure}

\subsubsection{Chromosome Representation}
A candidate plan is encoded as an ordered permutation chromosome of target waypoint nodes:
\begin{equation}
    C = [v_1, v_2, v_3, \dots, v_k], \quad v_j \in V
\end{equation}
For example: $[\text{Market} \rightarrow \text{Alley} \rightarrow \text{Library} \rightarrow \text{Caf\'e} \rightarrow \text{Home}]$.

\subsubsection{Multi-Objective Fitness Evaluation}
The fitness function penalizes distance and danger while rewarding clue discovery and punctual completion:
\begin{equation}
    \text{Fitness}(C) = - \left(w_1 \cdot D(C)\right) - \left(w_2 \cdot H(C)\right) + \left(w_3 \cdot R(C)\right) + \left(w_4 \cdot B(C)\right)
\end{equation}
where $D(C)$ represents cumulative travel distance, $H(C)$ denotes passage through high-threat alleys, $R(C)$ quantifies investigated clue sites, and $B(C)$ is a terminal punctuality bonus.

\subsubsection{Evolutionary Operators}
\begin{itemize}
    \item \textbf{Initialization:} 50 candidate routes generated randomly from valid graph connections.
    \item \textbf{Tournament Selection:} Subsets of $k=3$ individuals compete; the highest fitness candidate is selected as a parent.
    \item \textbf{Order Crossover (OX):} Preserves contiguous route sub-segments while preventing duplicate node visitation.
    \item \textbf{Swap Mutation:} Randomly swaps two waypoints ($p_m = 0.05$) to explore novel detours.
    \item \textbf{Elitism:} The top $5\%$ fittest candidates survive into subsequent generations without mutation.
\end{itemize}
The algorithm terminates after 50 generations (taking $<200\text{ ms}$ on CPU), dispatching the evolved itinerary to the agent controller.

\subsection{Neural Network Policy (Supervised Classification)}
For fast reflex choices without re-running combinatorial planners, a Multi-Layer Perceptron (MLP) acts as a reactive policy:
\begin{itemize}
    \item \textbf{Input Feature Vector ($\mathbf{x} \in \mathbb{R}^7$):} Normalized state features:
    \begin{equation}
        \mathbf{x} = [\text{loc\_id}, \text{dist\_goal}, \text{nearby\_npcs}, \text{clue\_flag}, \text{threat\_level}, \text{caution}, \text{curiosity}]
    \end{equation}
    \item \textbf{Target Space ($y$):} Discrete action classes $y \in \{\text{Move}, \text{Talk}, \text{Examine}, \text{Wait}, \text{Flee}\}$.
    \item \textbf{Topology:} Input ($7$) $\rightarrow$ Dense ($32$, ReLU) $\rightarrow$ Dense ($16$, ReLU) $\rightarrow$ Softmax ($5$).
    \item \textbf{Training:} Optimized using Adam and cross-entropy loss over simulation logs; evaluated via held-out confusion matrices and F1-scores.
\end{itemize}

\subsection{Unsupervised Trajectory Clustering (K-Means)}
To study emergent playstyles without manual behavioral tagging, simulation trajectory summaries (total distance, conversational volume, clue inspections, idle ticks) are clustered using K-Means ($k=3$):
\begin{enumerate}
    \item \textbf{The Inquisitor:} High spatial displacement, frequent clue inspections, moderate dialogue.
    \item \textbf{The Socialite:} Low transit distance, long stays at the Caf\'e and Town Square, high dialogue frequency.
    \item \textbf{The Cautious Resident:} Avoids high-threat alleys, returns home early, minimizes risky investigations.
\end{enumerate}

\subsection{Grounded LLM Dialogue Engine}
The LLM is invoked solely when linguistic exchange occurs. A controlled context-injection pipeline compiles the character's private memories and persona into a strict JSON contract:

\begin{lstlisting}[caption={Example Grounded LLM Prompt Template}]
{
  "system": "You are Ahmed, a 42-year-old cafe owner. Cautious and guarded with strangers. Answer strictly based on your private memories. If you did not witness an event, truthfully say you do not know.",
  "npc_profile": { "name": "Ahmed", "traits": ["cautious", "observant"], "current_goal": "Keep cafe safe" },
  "relevant_memories": [
    "[09:30 AM] Brewed coffee for morning patrons.",
    "[10:00 AM] Sat reading the town newspaper."
  ],
  "player_input": "Did you see who dropped the golden watch at the Market?",
  "output_format": "JSON: {\"reply\": string, \"mood\": string}"
}
\end{lstlisting}

When evaluated by the model, this structured context produces a grounded, in-character response without leaking unobserved town events:

\begin{lstlisting}[caption={Example Grounded LLM Response Output}]
{
  "reply": "A golden watch? I haven't left this cafe all morning, so I couldn't tell you. You might want to check down at the Market yourself.",
  "mood": "neutral"
}
\end{lstlisting}

Because Ahmed's prompt excludes events from the Market, he cannot leak information regarding the stolen watch, preserving narrative authenticity.

Believable multi-agent social behavior requires \textbf{information asymmetry}. Knowledge must diffuse across the environment through physical encounters rather than instantaneous global updates (Figure~\ref{fig:town_diffusion}).

\subsection{Information Diffusion Scenario Walkthrough}
\begin{enumerate}
    \item \textbf{Detection (10:00 AM):} A gold pocket watch is dropped at Market Stall 4. Sara is located at the Market node; her sensory filter logs the clue. Ahmed is at the Caf\'e node ($d=7$ ticks away); his sensory radius detects nothing.
    \item \textbf{Goal Formulation and Pathfinding (10:05 AM):} Sara establishes a goal: ``Warn Ahmed at Caf\'e.'' She runs $A^*$ search to compute the route: $\text{Market} \rightarrow \text{Town Square} \rightarrow \text{Caf\'e}$.
    \item \textbf{Physical Transit (10:05--10:25 AM):} Sara traverses intermediate nodes over multiple clock ticks. Ahmed remains reading at the caf\'e, completely oblivious.
    \item \textbf{Social Encounter (10:30 AM):} Sara enters the Caf\'e node and executes $\text{Talk}(\text{Ahmed})$. The dialogue model generates speech: \textit{``Ahmed, look what was dropped at the Market!''} Ahmed's memory ledger appends: \texttt{[10:30 AM] Sara reported finding a gold watch at Market.}
\end{enumerate}

\section{Quantitative Evaluation Framework}
% =========================================================================

The system's performance is rigorously measured across 100 scenario trials:

\subsection{Core Evaluation Metrics}
\begin{enumerate}
    \item \textbf{Goal Success Rate:} Percentage of episodes where NPCs fulfill assigned primary goals within 50 ticks (Target: $\ge 80\%$).
    \begin{equation}
        \text{Success Rate} = \frac{N_{\text{completed}}}{N_{\text{total}}} \times 100\%
    \end{equation}
    \item \textbf{Path Optimality Ratio:} Ratio of optimal $A^*$ path length to actual traversed distance (Target: $\ge 92\%$).
    \begin{equation}
        \text{Optimality} = \frac{\text{Length}(A^*)}{\text{Distance}_{\text{traveled}}}
    \end{equation}
    \item \textbf{Memory Consistency Rate:} Automated verification that conversational statements contain zero contradictions against memory logs (Target: $\ge 95\%$).
    \begin{equation}
        \text{Consistency} = 1 - \frac{N_{\text{contradictions}}}{N_{\text{dialogues}}}
    \end{equation}
    \item \textbf{Goal Alignment Score:} Proportion of actions directly advancing top-priority goals versus idle ticks (Target: $\ge 85\%$).
    \begin{equation}
        \text{Alignment} = \frac{A_{\text{goal-relevant}}}{A_{\text{total actions}}}
    \end{equation}
    \item \textbf{ANN Classification F1-Score:} Weighted F1-score of the MLP policy on held-out test data (Target: $\ge 0.88$).
    \begin{equation}
        \text{F1} = 2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}
    \end{equation}
\end{enumerate}

\section{Summary and Key Advantages}
% =========================================================================

\begin{enumerate}
    \item \textbf{Pragmatic Resource Footprint:} Runs 100\% on consumer-grade laptop CPUs without requiring expensive cloud GPUs or model fine-tuning.
    \item \textbf{Comprehensive AI Coverage:} Unifies classical search ($A^*$), evolutionary computation (GA), supervised learning (MLP), unsupervised clustering (K-Means), and grounded generative AI.
    \item \textbf{Verifiable Grounding:} Restricting the language model to dialogue while anchoring physical reality in deterministic simulation code guarantees that generative hallucinations cannot violate game physics.
\end{enumerate}
